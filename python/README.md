# Auctor Utilities

Auctor Utilities is a standalone Python library for diagnostics, filesystem operations, data processing, and terminal interaction.

## Install

```sh
python -m pip install auctor-utils
```

The distribution is named `auctor-utils`; import it as `Auctor`:

```python
from Auctor import __version__
```

Python 3.10 or newer is required. See the [project README](../README.md) for the full overview and documentation.
